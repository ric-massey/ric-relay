How this gets read

Apex has no official API and no match log. Every stats site reads the same keyhole: the three trackers equipped on the banner of the legend you're currently playing. Nothing else about a player is exposed. A legend with no tracker on it has, as far as the internet is concerned, never been played.

So this isn't a logbook, it's an accumulator. pull-apex.py takes a snapshot, keeps the highest number it has ever seen for each tracker, and writes one history point a day. The totals only ever grow — the honest line is the slope.

Career kills is the account-wide figure Apex shows in the lobby when you click your gamertag, and it's the one number no API returns. Respawn made Career Kills and Career Wins trackers for the 5th anniversary in 2024; without those, the career row here is typed in by hand and stamped with the date it was read.
