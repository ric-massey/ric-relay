SIEGE CONDUCTOR — how to send it to friends
===========================================

UPDATED 2026-09-17. This used to say "you can't text the app itself — put it
online once with Netlify Drop and text the link." That step is done, and it
wasn't Netlify: Siege Conductor is part of Ric's site now, so it has had a real
link for months. You don't have to upload anything.


STEP 1 — Send this link
-----------------------

  https://ricmassey.com/projects/siege-conductor/

That link IS the app. Paste it into Messages / WhatsApp / email — anything. It's
a normal web link, so nothing blocks it, and it opens on any phone or computer.

It's also reachable from Ric's Terminal: it's the Siege Conductor card in the
Workbench room, and typing `siege` (or `conductor`) at the terminal prompt opens
it.

To update it: edit the files in this folder and push the site. GitHub Pages
redeploys, and everybody's link and home-screen icon keep working — the service
worker (`sw.js`) picks the new version up.


STEP 2 — What your friend does (tell them this)
-----------------------------------------------

On iPhone:
  1. Tap the link (it opens in Safari).
  2. Tap the Share button (square with an arrow).
  3. Tap "Add to Home Screen."
  4. Tap "Add." Done — it's now an app icon (the crossed sabers).

On Android:
  1. Tap the link (opens in Chrome).
  2. Tap the ⋮ menu, then "Add to Home screen" / "Install app."

On Mac/Windows:
  - Just open the link in any browser. (Chrome/Edge also show an
    "install" icon in the address bar if they want an app window.)

After the first open it works even with no internet, and it remembers which
step you're on.


If you ever want a standalone copy
----------------------------------

Only needed if you want a version that is NOT part of ricmassey.com — a private
copy for one group, say, or a test of an edit you don't want published.

  1. Go to:  https://app.netlify.com/drop
  2. Drag the WHOLE "siege-conductor" folder onto the page.
  3. It gives you a link like  https://something-random-1234.netlify.app
  4. Make a free account when it asks, so the link stays and can be renamed.

Other free drag-and-drop hosts that work the same way: https://tiiny.host,
https://surge.sh (a bit more technical).


Notes
-----
- iPhone uses the "apple-touch-icon.png" for the home-screen icon.
- The "icon-1024.png" file isn't required for the web app; it's just a
  big master copy in case you ever want it.
- Every path inside the app is relative, which is why the same folder works at
  ricmassey.com/projects/siege-conductor/, at the root of a Netlify site, and
  opened straight off the disk. Keep it that way.
