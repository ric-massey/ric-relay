owner names by county

ATLAS can tell you which agency manages a piece of ground anywhere in the country, and read you its legal description. Putting a name to a private parcel is the county's business, and every county publishes differently — so you point it at one, once.

add a county myself

Find the county's ArcGIS parcel layer — search "<county> GIS REST services parcels". You want the URL of a single layer, ending in a number. Open it in a browser first: it should list the fields by name.

Put {apn} where the parcel number goes and ATLAS will fill it in.

These live in the database, not in the code — the website's repository is public, and which counties you look things up in is nobody else's business.
